# Overview

What am I building?

- Single player RTS inspired by creeper world. 
- all units NEED to move through the network as well. 

# Resources

three resources:
- stabilizer: used to power buildings units
- matter: used to build structures and units
- ore: converted into energy/matter

# base building

all resources distributed through nodes/graph
- nodes can be connected to each other
- nodes can be connected to the base

## buildings (names pending)

- reality core (core/nexus): 
  - main building (root of the network)
  - there can be multiple nexi
- collector: collects ore from 
  - stabilizes space
- relay: expands range units can be controlled, resources move faster between relays

unit production:
- consumes matter to make frames
- frames are then sent to front lines through the network
